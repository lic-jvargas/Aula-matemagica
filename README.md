# aula-matemagica
Matemágicos Hub es un repositorio educativo que integra recursos digitales, estrategias didácticas y herramientas TIC para fortalecer el pensamiento matemático. Su enfoque pedagógico promueve el aprendizaje activo, la resolución de problemas, la autonomía y la gamificación, favoreciendo experiencias de aprendizaje significativas e inclusivas.
