# Estándares Básicos de Competencias en Matemáticas

## Justificación

Los Estándares Básicos de Competencias constituyen un referente del Ministerio de Educación Nacional de Colombia para orientar los aprendizajes que se espera que los estudiantes desarrollen durante su proceso educativo.

En el área de Matemáticas, los estándares permiten organizar el trabajo pedagógico alrededor de diferentes tipos de pensamiento matemático y de los procesos relacionados con la resolución de problemas, el razonamiento, la comunicación, la modelación y la formulación y ejecución de procedimientos.

En **Aula Matemágica**, los Estándares Básicos de Competencias se incorporan como un referente para relacionar los recursos educativos con los procesos de aprendizaje matemático. Esto permite que los videos, presentaciones, actividades y recursos digitales no sean utilizados únicamente como herramientas tecnológicas, sino como apoyos para desarrollar competencias matemáticas.

## Organización de los Estándares de Matemáticas

Los Estándares Básicos de Competencias en Matemáticas se articulan con diferentes pensamientos y sistemas matemáticos:

* **Pensamiento numérico y sistemas numéricos**
* **Pensamiento espacial y sistemas geométricos**
* **Pensamiento métrico y sistemas de medidas**
* **Pensamiento aleatorio y sistemas de datos**
* **Pensamiento variacional y sistemas algebraicos y analíticos**

Estos pensamientos permiten abordar las Matemáticas desde diferentes situaciones y contextos, favoreciendo una formación matemática integral.

## Relación con Aula Matemágica

Los estándares sirven como referente para organizar los recursos educativos del repositorio de acuerdo con los aprendizajes y procesos matemáticos que se pretenden desarrollar.

Por ejemplo:

| Recurso                                 | Pensamiento matemático relacionado                          |
| --------------------------------------- | ----------------------------------------------------------- |
| Valor posicional                        | Pensamiento numérico y sistemas numéricos                   |
| Unidades de medida                      | Pensamiento métrico y sistemas de medidas                   |
| Tabla de frecuencia y gráfico de barras | Pensamiento aleatorio y sistemas de datos                   |
| Geometría                               | Pensamiento espacial y sistemas geométricos                 |
| Patrones y relaciones                   | Pensamiento variacional y sistemas algebraicos y analíticos |

Esta organización permite establecer una relación entre el recurso educativo, el contenido matemático y el referente curricular correspondiente.
