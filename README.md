# aula-matemagica
Matemágicos Hub
Repositorio educativo para el aprendizaje de las matemáticas
Matemágicos Hub es un repositorio educativo que integra recursos digitales, estrategias didácticas y herramientas TIC para fortalecer el pensamiento matemático. Su propuesta promueve el aprendizaje activo, la resolución de problemas, la autonomía y la gamificación como estrategias para generar experiencias de aprendizaje significativas e inclusivas.
Propósito
Organizar y compartir recursos educativos digitales que apoyen la enseñanza y el aprendizaje de las matemáticas, facilitando el acceso a materiales pertinentes para docentes y estudiantes.
Organización
Los recursos se organizan de acuerdo con:
Grados escolares.
Temáticas matemáticas.
Recursos didácticos.
Actividades gamificadas.
Resolución de situaciones problema.
Herramientas TIC.
Recursos educativos
El repositorio puede integrar:
Guías y talleres.
Videos educativos.
Mapas mentales e infografías.
Actividades gamificadas.
Actividades de aprendizaje.
Situaciones problema.
Recursos digitales interactivos.
Gamificación
La propuesta incorpora elementos de gamificación para favorecer la motivación, la participación y el aprendizaje mediante retos, actividades interactivas y experiencias que convierten las matemáticas en un espacio de exploración y descubrimiento.
Enfoque pedagógico
Matemágicos Hub busca favorecer un aprendizaje activo y significativo, donde el estudiante participe en la construcción del conocimiento, desarrolle estrategias para resolver problemas y utilice recursos tecnológicos como apoyo para su proceso de aprendizaje.
Usuarios
El repositorio está dirigido principalmente a:
Estudiantes de educación básica y media.
Docentes de matemáticas.
Instituciones educativas.
Familias interesadas en apoyar el aprendizaje matemático.
Recursos complementarios
Los recursos audiovisuales pueden complementarse con el canal de YouTube @nivelmatematico y otras herramientas digitales utilizadas en las experiencias de aprendizaje.
